# Support

## How to file issues and get help

This research project uses
[GitHub Issues](https://github.com/microsoft/neuro-formal-verification/issues)
for bug reports, feature requests, usage questions, and research feedback.
Search existing issues before opening a new one.

For setup and usage, start with the [paper artifact guide](paper/README.md) or
the [prototype reviewer guide](workflow/README.md). When reporting a problem,
include the component, repository revision, operating system, tool versions,
reproduction steps, and expected versus observed behavior.

Inspect logs and attachments before sharing them. Do not include access tokens,
personal information, confidential source code, or other sensitive content.
Report security vulnerabilities privately using [SECURITY.md](SECURITY.md),
not through GitHub Issues.

## Microsoft Support Policy

Support for Neuro-Formal Verification is limited to the resources listed above.
